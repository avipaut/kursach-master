Formula Syntax Help

You can create formulas to calculate values automatically. Use the fx button next to any cell to add a formula.

Basic Operations

  • Addition: [Value] + [Cost]
  • Subtraction: [Revenue] - [Cost]
  • Multiplication: [Quantity] * [Price]
  • Division: [Total] / [Count]
  • Percentage: [Actual] / [Target] * 100

Examples

Progress calculation: [Значение] / [Цель] * 100

Profit calculation: [Revenue] - [Cost]

Average calculation: ([Value1] + [Value2] + [Value3]) / 3

Notes:

  • Column names must be enclosed in square brackets: [Column Name]
  • Formulas are evaluated when you save the KPI data
  • Use standard mathematical operators: +, -, *, /, ()
  • If a value cannot be converted to a number, it will be treated as 0
