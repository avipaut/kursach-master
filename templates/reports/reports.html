Как использовать отчеты
  1. Выберите тип отчета из выпадающего списка или нажмите на одну из карточек выше
  2. Выберите доску для анализа или оставьте "Все доски" для включения всех задач
  3. Выберите временной период для анализа
  4. Нажмите "Создать отчет" для просмотра данных
  5. Используйте опции экспорта для загрузки отчета в различных форматах
Отчеты помогают выявлять тенденции, отслеживать прогресс и принимать решения на основе данных.
